# TCO-анализ: as-is vs to-be (горизонт 3 года)

Модель совокупной стоимости владения (TCO) для текущей архитектуры (DWH SQL Server 2008 +
Camel ESB + Power BI) и целевой (облачная событийная платформа Data Mesh + портал
самообслуживания). Горизонт — 3 года трансформации.

Условные обозначения. Абсолютные суммы в учебном кейсе не зафиксированы (нет бюджета),
поэтому модель построена в относительных единицах:
- `X` — совокупные затраты as-is в год 1 (базовый год, 100 %);
- `Y` — совокупные затраты to-be в год 1, `Y ≈ 1.1·X` (год 1 включает разовую миграцию);
- статьи затрат — доля (%) от соответствующей базы; динамика — % прироста/снижения в год.

## Сравнение и экономический эффект

| Показатель | As-is | To-be | Δ |
|------------|-------|-------|---|
| Итого за 3 года | ≈3.3·X | ≈3.1·X | −5 % без учёта качественных эффектов |
| Run-rate года 3 | 120 %·X | 96 %·X | −20 % ежегодно начиная с года 3 |
| Тренд после 3 лет | рост ~+9 %/год (данные, лицензии, легаси) | стабилизация/снижение за счёт self-service | расхождение растёт |
| Избегаемые разовые затраты | — | — | Модернизация/замена лицензий SQL Server при вынужденном апгрейде: ≈0.3·X единовременно |
| Время сложного отчёта | часы | минуты | ускорение аналитических циклов |
| Time-to-market нового дата-продукта | месяцы (очередь к команде DWH) | дни/недели (self-service домена) | монетизация ИИ, новые регионы |
| Свежесть данных | batch (сутки) | near-real-time (минуты) | риск-метрики банка, мониторинг ИИ |

Точка окупаемости: разрыв по run-rate открывается с года 3 (−20 %), накопленный эффект
(экономия года 3 + избегаемый апгрейд лицензий ≈0.3·X + сокращение cost of delay) выводит
трансформацию в положительную зону на 3–4-й год эксплуатации; с года 4 расхождение
увеличивается (to-be стабилен, as-is растёт ~9 %/год с объёмом данных).

## Анализ чувствительности

| Фактор | Влияние на модель |
|--------|-------------------|
| Рост объёма данных +15 %/год (кейс: сотни ТБ) | As-is дорожает быстрее (вертикальный scaling); to-be — горизонтальное масштабирование, рост ~линейный |
| Цена облака ±20 % | Σ to-be 3 года меняется на ±6 %·X; точка окупаемости сдвигается на ±6 мес |
| Срыв графика вывода легаси (риск T6) на 6 мес | To-be годы 2–3: +9–11 %·X в год на двойную эксплуатацию — главный риск модели |
| Низкий adoption self-service BI | Экономия времени аналитиков (12 %→6 % от Y) не достигается: откат до уровня as-is ≈ +6 %·X/год |
| Регуляторный инцидент на легаси (as-is) | Разовые потери ≈0.2–0.6·X — асимметричный риск в пользу трансформации |
